Kalkulator IP & Subnet

Masukkan IP bebas + prefix /0–/32. Boleh juga langsung menulis IP/prefix atau IP mask. Klik kotak hasil untuk menyalin.

Reverse Calculator: Sizing Berdasarkan Kebutuhan Host

Masukkan kebutuhan tiap divisi/VLAN. Aplikasi memilih prefix paling efisien. Isi blok induk (opsional) untuk mendapat alokasi IP otomatis tanpa overlap.

Multi-Subnet Korporat (Bagi Rata)

Bagi satu blok jaringan kantor menjadi N subnet berukuran sama untuk VLAN/interface.

IP Match Checker & Validator Gateway

Cek apakah dua IP berada dalam subnet yang sama atau butuh routing. Hasil dihitung dari sudut pandang masing-masing perangkat.

Perencana IP Publik (ISP, NAT Pool, DMZ)

Alokasikan blok publik dari ISP untuk gateway, NAT pool, dan server DMZ, lengkap dengan script RouterOS. Blok non-publik (privat, CGNAT, dokumentasi) diberi peringatan.

Overlap Checker & Ruang Kosong (IPAM)

Tempel daftar alokasi, satu entri per baris: label IP/prefix (label opsional, baris berawalan # diabaikan). Tool mendeteksi tabrakan antar-blok dan menampilkan ruang kosong di blok induk.

Generator Konfigurasi MikroTik

Isi interface dan IP router (format IP/prefix). Isi VLAN ID bila interface adalah VLAN, interface VLAN akan dibuat otomatis.

Troubleshooting & Edukasi Subnet

Urutan diagnosa cepat jika dua perangkat tidak bisa berkomunikasi:

  1. Cek link fisik/Wi-Fi dan VLAN port (ada link, tidak ada error).
  2. Cek IP, subnet mask, dan gateway di kedua perangkat (ipconfig / ip a).
  3. Ping gateway. Jika gagal, masalah ada di segmen lokal.
  4. Ping IP publik (mis. DNS 1.1.1.1). Jika gagal, cek route default dan NAT.
  5. Ping nama domain. Jika gagal, masalah ada di DNS.
